# Pizza Shop Website

Pizza Shop Website is a web-based food ordering system developed using PHP, MySQL, HTML, CSS, Tailwind CSS, and JavaScript. The project allows users to explore different food categories, add items to cart, place orders, and contact the shop through a contact form. It also includes an admin panel for managing products, orders, and dashboard statistics.

## Project Description

This project is designed for an online pizza and fast-food shop where customers can view menu items, select products, manage their cart, and complete the checkout process. The system also provides user authentication features such as signup, login, logout, and password change.

The admin side allows authorized users to view total orders, registered users, products, recent orders, manage pizzas/products, and update order statuses.

## Features

### User Features
- User signup and login system
- View homepage with food sections
- Browse menu categories
- View pizzas, burgers, pasta, shawarma, sandwiches, spaghetti, and deals
- Add products to cart with quantity
- View cart total
- Remove items from cart
- Checkout and place orders
- Contact form for customer messages
- Logout functionality

### Admin Features
- Admin login system
- Admin dashboard
- View total orders, total products, and registered users
- View recent orders
- Manage products/pizzas
- Add and delete products
- View customer orders
- Update order status:
  - Pending
  - Preparing
  - Delivered
  - Cancelled
- Manage product categories
